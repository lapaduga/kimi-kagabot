# Кагаботик: Paint-хищник

Игра-песочница, где рисунок — это еда, рельеф и мотив одновременно.
Чистый фронтенд, без сборки: **открыть `index.html` двойным кликом** (работает с `file://`).

## Запуск тестов

```
node --test tests/
node --check js/*.js
```

## Управление

- Инструменты: кисть, маркер, аэрозоль, заливка, ластик. Размер/непрозрачность — слайдеры.
- `Ctrl+Z` — отменить штрих (съеденное Undo не возвращает — оно живёт в маске `eaten`).
- `B` / кнопка 🍬 — приманка (3 заряда, +1 каждые 5 с): бросьте каплю, он придёт.
- `S` / кнопка 😴 — усыпить в банку / разбудить.
- Ластик рядом с ним — он пугается и убегает.
- 💾 — экспорт PNG (бумага + краска + Кагаботик).

## Правила мира

- Насыщенный цвет = еда (красный/маджента/лайм — самое вкусное). Графит, чёрный, белый — не еда:
  шедевр в графите переживёт хищника. Это эстетическая плата: скучно рисовать = безопасно.
- Верхушка краски в каждой колонке — платформа. Ступенчатая лесенка (шаг ≤ 22 px) — путь наверх.
- Цель выше досягаемости → он честно считает `shortfall = (опора − досягаемость) − цель`,
  показывает линейку «нужно/хватает/не хватает» и советует нарисовать ступеньку,
  прыгает 4–5 раз с эскалацией, обижается. Построите ступеньку — бросается есть немедленно.
- Голод: 0.016/с; охота с 0.22; сытый (живот ≥ 1) спит ~15–18 с — окно для шедевра.
- Мутации каждые 5 обедов: длинноногий, рогатый, прыг-скок (двойной прыжок), пятнистый, светящийся, великан.
- Метрика: сохранность красок = (нарисовано − съедено)/нарисовано. Рекорды — в localStorage.

## Осознанные упрощения (дизайн-док §6)

Персонаж всегда поверх краски (конвенция doodle). Арки — своды (one-way платформы).
Поиск пути по пикселям не нужен: heightmap достаточно.
